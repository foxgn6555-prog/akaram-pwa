# ADR 007 — المراقبة منذ اليوم الأول

**الحالة:** مقبول · **التاريخ:** 2026-08

## القرار
- Sentry اختياري بالكامل: يُفعَّل فقط عند وجود `VITE_SENTRY_DSN` — التطبيق يعمل كاملاً بدونه.
- الوصول عبر `logger` فقط — لا استدعاء Sentry مباشر من المكونات.
- تنقية بيانات الطلبات في `beforeSend` — لا بيانات موظفين تُرسل للطرف الثالث.
- MFA إلزامي لدور `super_admin` (يُفعَّل من إعدادات Supabase Auth) + سياسة كلمات مرور.

## النتيجة
تكلفة صفر عند عدم الحاجة، تغطية كاملة عند التفعيل.
