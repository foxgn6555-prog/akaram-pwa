# ADR 006 — سياسة تعارض Offline (تصحيح فجوة v3)

**الحالة:** مقبول · **التاريخ:** 2026-08

## السياق
v3 دعت لـ Optimistic Updates دون أي سياسة تعارض — أخطر ثغرة منطقية في PWA.

## القرار
1. كل الجداول القابلة للتعديل تحمل `version` يرفعه trigger `app.bump_version`.
2. الطفرة تحمل `baseVersion`؛ رفض الخادم عند mismatch.
3. مصفوفة استراتيجيات لكل entity (انظر `src/lib/offline/conflict.resolver.ts`):
   - **server-wins**: المال والرواتب والميزانية — لا طفرات دون اتصال أصلاً.
   - **client-wins**: تفضيلات غير حرجة (قراءة إشعار، تسجيل حضور اليوم).
   - **reject**: الافتراضي — أبلغ المستخدم ودعه يعيد القرار بنسخة محدثة.
4. طابور طفرات `mutation-queue.ts` (localStorage؛ مسار ترقية موثق لـ IndexedDB).

## النتيجة
لا صمت بيانات ولا كسب صامت خاسر — كل تعارض له مصير معلن وموثق.
