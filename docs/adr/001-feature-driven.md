# ADR 001 — هيكلية Feature-Driven

**الحالة:** مقبول · **التاريخ:** 2026-08

## السياق
كنا بين تقسيم تقني (hooks/, components/ بالجذر) وتقسيم بالميزات.

## القرار
Feature-Driven: كل ميزة تملك `hooks/ + schemas/ + components/ + types.ts + index.ts`.
الاستيراد بين الميزات عبر `index.ts` العام فقط (قانون 3).

## النتيجة
إضافة/حذف ميزة = مجلد واحد. حدود واضحة تمنع التشابك. فرض جزئي عبر ESLint.
