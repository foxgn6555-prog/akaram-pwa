# ADR 002 — طبقة SDK (نقطة Supabase الوحيدة)

**الحالة:** مقبول · **التاريخ:** 2026-08

## القرار
- كل استدعاء Supabase داخل `src/services` حصراً — يفرضه ESLint (`no-restricted-imports`).
- كل domain = ملف SDK واحد (حد توجيهي 300 سطر) يمر عبر `sdkGuard` الذي يوحّد الأخطاء.
- انقسم `departments` عن `employees.sdk` عمداً (تصحيح عن v3: كانا في ملف واحد وسيكسران الحد).

## النتيجة
تغيير الباك-إند مستقبلاً = مجلد واحد. أخطاء موحدة قابلة للعرض الآمن.
