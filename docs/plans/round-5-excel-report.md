# الجولة ٥ — تصدير Excel بأعمدة قابلة للاختيار والترتيب (المرحلة ⑦)

## ١. ملاحظة صريحة عن مصدر الأعمدة

الخطة تقول «11 عموداً **كما في الطلب**» ولا تعداد لها في أي وثيقة بالمستودع
(فحصتُ كل `docs/`، ملف القرارات، والنماذج الأولية). فبنيتُ **١١ عموداً
افتراضياً معلناً** قابلاً للتعديل من الواجهة بلا إعادة نشر:

| # | العمود | المصدر |
|---|---|---|
| ١ | النوع (شارع/زقاق) | التخطيط |
| ٢ | الكود | التخطيط |
| ٣ | الاسم | التخطيط |
| ٤ | المحلة | التخطيط |
| ٥ | الطول (م) | التخطيط |
| ٦ | العرض (م) | التخطيط |
| ٧ | حالة التغطية | الزيارات (مؤكد/غير مؤكد/لم تُدخل) |
| ٨ | عدد الزيارات | الزيارات |
| ٩ | الآليات | الزيارات |
| ١٠ | إجمالي المكوث | الزيارات |
| ١١ | آخر زيارة (بغداد) | الزيارات |

**التعديل لا يحتاج كوداً:** لوحة «الأعمدة» تتيح إخفاء/إظهار/إعادة ترتيب،
والحفظ في القاعدة يستعيده.

## ٢. ما بُني

| الطبقة | الملف | المحتوى |
|---|---|---|
| منطق نقي | `export-columns.ts` | ٢١ تعريف عمود (١١ أماكن + ١٠ زيارات) · `resolveColumns` · `moveColumn` · `toggleColumn` · `toReportRows` · `totalRow` · `baghdadTime/Day` |

| واجهة | `ExportColumnsPanel.tsx` | اختيار · ترتيب (↑↓) · إظهار/إخفاء · **معاينة حيّة** · حفظ |
| صفحة | `OpsMapPlanningTablePage.tsx` | CSV ← **Excel حقيقي** + تطبيق الفلاتر على الملف + تسجيل التصدير |
| اختبارات | ٣ ملفات | ٢٩ منطق + ١٨ عقد + ٦ بناء ملف فعلي |

## ٣. القرار التصميمي: مسار واحد لا مسارين

المعاينة على الشاشة والملف يُبنيان بـ**نفس الدالة** `toReportRows`، فما تراه
في المعاينة هو ما يخرج في Excel حرفياً. أي مسارين منفصلين كانا سينحرفان بالتأكيد.

## ٤. حمايات مثبتة باختبار على PostgreSQL حقيقي

| الحالة | النتيجة |
|---|---|
| حفظ تفضيل بلا عمود مرئي | `EXPORT_COLUMNS_EMPTY` مرفوض |
| صنف `pdf` | `EXPORT_KIND_INVALID` مرفوض |
| حفظ بلا تسجيل دخول | `AUTH_REQUIRED` مرفوض |
| مصفوفة غير مصفوفة | `EXPORT_COLUMNS_INVALID` مرفوض |
| مستخدم ب لا يرى تفضيل أ | `[]` ✓ |
| التحديث لا يُنشئ صفاً ثانياً | صف واحد ✓ |
| عدد صفوف سالب في سجل التصدير | يُقصّ إلى ٠ ✓ |
| عمود محذوف من الكود بقي في تفضيل قديم | يُتجاهل — لا عمود شبح |
| إخفاء كل الأعمدة من الواجهة | مرفوض (الزر معطَّل + القاعدة ترفض) |

## ٥. معايير القبول الثلاثة من الخطة

| المعيار | التحقق |
|---|---|
| «الملف يطابق الفلاتر» | صفوف التصدير تُشتق من `rows` المفلترة — مثبت في `exp-export-contract` |
| «ترتيب الأعمدة يُحفظ ويُسترجع» | `map_export_prefs` + RLS + استرجاع عند الفتح |
| «ترويسة وطباعة» | `buildExcelReport` (هوية الشركة) + `orientation: 'landscape'` |
