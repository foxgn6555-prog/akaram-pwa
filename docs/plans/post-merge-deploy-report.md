## ٣ · عيب قائم في `deploy.yml` — مكتشَف لا مُصلَح

### المشكلة
```
deploy = 47,600 ملف
  ├─ 45,699  node_modules/     ← حمولة زائدة
  ├─    950  dist/             ← نسخة مكرّرة من الجذر
  └─  1,901  الحزمة الفعلية
```

### السبب (سطر بسطر)
```bash
git checkout --orphan deploy
git rm -rf .          # يحذف الملفات **المتتبَّعة** فقط
                      # node_modules/ ليست متتبَّعة ⇒ تبقى على القرص
cp -r dist/. .
git add -A -f         # ← -f يتجاوز .gitignore
                      # ⇒ يضيف node_modules/ و dist/ قسراً
```

### الأثر الحقيقي — محدود
- **لا يكسر الموقع:** `index.html` يشير إلى `/assets/...` وكلها موجودة ✔
- `assets/` و`dist/assets/` **متطابقان** (نفس البصمة `d9be1af1`) — لا تضارب إصدارات
- يستهلك تخزيناً وعرض نطاق زائداً، ويُبطئ `git clone`، ويكشف شيفرة الحزم الداخلية

### لماذا لم أُصلحه في هذه الجولة
إصلاحه يستلزم تعديل `deploy.yml` ⇒ **تشغيل نشر جديد** على الإنتاج. لم تُطلب مني
جولة نشر ثانية، والعيب لا يعطّل شيئاً. **الإصلاح المقترح (سطر واحد):**
```diff
-          git add -A -f
+          git add -A
+          git reset -q node_modules dist
```
أو الأنظف: `git clean -fdx node_modules` قبل `cp -r dist/. .`.
