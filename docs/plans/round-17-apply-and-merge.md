## ③ عيب ثانٍ وُجد وأُصلح — تسرّب مخرجات npm

ملف `20261125000100` كان فيه سطر:

```
npm warn exec The following package was not found and will be installed: vite-node@6.0.0
```

تسرّب من `npx vite-node … > file.sql` لأن الرسالة تُطبع على stdout.

**كان سيفشل الإنتاج** عند السطر ٢٢ بـ`syntax error`. مرّ من tsc وeslint
وvitest لأن **لا اختبار ينفّذ ملفات الهجرة فعلياً**.

**الإصلاح:** حُذف السطر.

**العقد الجديد:** `tests/contract/migration-hygiene-contract.test.ts`
(٦ اختبارات) يفحص كل الهجرات: مخرجات npm · `added N packages` · أول سطر ·
BOM ومحارف تحكّم.

**اختبارُ العقد:** أعدت إدراج السطر يدوياً ⇒ **سقط اختباران**.

## ⑦ الدروس — مكتوبة لتُقرأ

1. **لا أكتب دالة إنتاج من الذاكرة.** المصدر هو الملف.
2. **إن لم أستطع تطبيق ملف كاملاً، أتوقف وأسأل** — لا أختصر.
3. **الاختبار السلوكي شرط قبل الادّعاء.** `length(prosrc)` وحده لا يكفي.
4. **الهجرات المولَّدة تحتاج عقداً يمنع تسرّب المخرجات** — أُضيف.
5. **`schema_migrations` يُسجَّل بعد التحقق، لا قبله.**
