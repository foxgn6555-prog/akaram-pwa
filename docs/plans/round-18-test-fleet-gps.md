## ٤. تفسير أرقام قد تبدو غير متوقعة (بصدق)

1. **عدد الآليات في الرياض = ٢١ لا ٣.** الأجهزة فيزيائية حقيقية تتحرك في بغداد، فجهاز مخصّص «لزون» قد يسجّل نقاطاً داخل زون آخر. المحرّك يعيّن الزيارة حسب **موقع النقطة**، لا حسب الزون المقصود عند الربط. هذا سلوك صحيح ومطلوب — ويعني أن خريطة الأزون لا تُطبّق «حصاراً» صناعياً.
2. **الوليد: ١٥١ شارع مقابل ٤ أزقة فقط** — تغطية الشوارع في تلك المنطقة أعلى بكثير من الأزقة.
3. **الزعفرانية: متوسط مكوث ٥٩ث فقط** — مرور سريع؛ الحد الأدنى للمحرّك ٦٠ث لكن المتوسط يقلّ لأن نصف الزيارات شبه عابرة.

## ٥. الحذف الكامل عند الانتهاء

الملف: **`scripts/teardown-test-fleet.sql`** — معاملة واحدة (`begin … commit`)، نجاح كامل أو تراجع كامل.

```bash
psql "$DATABASE_URL" -f scripts/teardown-test-fleet.sql
```

**نقطة حرجة:** `map_visits.vehicle_id` مفتاحه **`ON DELETE SET NULL`**، لذا حذف الآليات مباشرة يُنتِج ١٩١٥ زيارة يتيمة بلا آلية بدل حذفها. السكربت يحذف `map_visits` **أولاً** صراحةً.

### تحقّق مُسبق من الأثر (نُفِّذ على القاعدة الحيّة)

فحص آلي شامل لـ**كل** المفاتيح الأجنبية الـ٦٤ التي تشير إلى `employees` أو `garage_vehicles`
(`pg_constraint` + `query_to_xml` لعدّ الصفوف فعلياً في كل جدول):

| الجدول | الصفوف التابعة |
|---|---:|
| `map_visits` | ١٩١٥ |
| `gps_vehicle_bindings` | ٢٤ |
| `garage_vehicles.driver_employee_id` | ٢٤ |
| **باقي ٦١ مفتاحاً** (حضور، رواتب، طلبات، إجازات، سلف، خزينة، صيانة، `ts_*`، `gps_zone_*`، …) | **٠** |

⇒ لا يوجد أثر جانبي خارج الأسطول التجريبي. الأجهزة والمواقع الحقيقية (`gps_devices`, `gps_device_positions`, `gps_device_position_history`) **لا تُحذف**.

### تصديق السكربت (نُفِّذ فعلياً ثم تُراجع)

نُفِّذ جسم السكربت كاملاً على القاعدة الحيّة **داخل معاملة ثم `rollback`** — كل جملة `delete`/`update` عملت بلا خطأ، والنتيجة داخل المعاملة:

| القياس | القيمة |
|---|---:|
| آليات `TEST-%` متبقية | ٠ |
| سائقون `DRV-T%` متبقيون | ٠ |
| زيارات متبقية | ٠ |
| **زيارات يتيمة (`vehicle_id IS NULL`)** | **٠** |
| ربط متبقٍ | ٠ |

ثم `rollback` ⇒ عاد كل شيء: ٢٤ آلية · ٢٤ سائقاً · ٢٤ ربطاً · ١٩١٥ زيارة · ٠ يتيمة.
**لم يُحذف أي صف نهائياً.** السكربت جاهز للتنفيذ النهائي بإزالة `rollback` (أو تنفيذ الملف كما هو).

## ٦. فلترة التقارير (المتطلب الأصلي)

لم يُضَف بعد كود فلترة `TEST-` في واجهات التقارير. المعرّفات الثلاثة للفلترة:
- `garage_vehicles.plate_number LIKE 'TEST-%'`
- `employees.employee_number LIKE 'DRV-T%'`
- `gps_vehicle_bindings.notes LIKE '%اختباري%'`
