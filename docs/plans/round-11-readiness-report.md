## ② ما يراه الموظف الآن — الحقيقة لا الطموح

الموظف يفتح `/ops-room/map-planning/import` ← **شاشة فارغة**. هذا تسلسل الفشل:

### الخطوة ① «سكربت الزون» — تفشل

```
mapImportSdk.zoneScript(zoneId)
  → supabase.rpc('map_osm_script', { p_zone })
  → PostgREST: PGRST202  «الدالة غير موجودة في schema التعرّض»
```

**السبب المزدوج:**
1. `app.map_osm_script` **غير موجودة** — الهجرة ١٣٠٠ لم تُطبَّق.
2. **وهي في schema `app`** — وPostgREST يكشف `public` فقط. لا صف `pgrst.db_schemas`
   في `pg_db_role_setting`، ولا أي `.schema('app')` في العميل.

الصفحة تلتقط الخطأ بـ`catch { setScript('') }` ⇒ **مربع السكربت يبقى `— يُولَّد من القاعدة —`**.

### الخطوة ② «إسقاط ملف .osm» — تفشل قبل الملف

```ts
const { data: zones = [] } = useMapZones()   // public.map_zones → []
```

`map_zones` غير موجودة ⇒ مصفوفة فارغة ⇒ `activeZoneId = null` ⇒
**لا زر زون، ولا `handleFile`، ولا إمكانية اختيار ملف.**

**وهنا العيب الحرج:** لا توجد **أي** رسالة فراغ في الصفحة. الموظف يرى إطاراً أبيض
بلا تفسير، ولا يعرف أن السبب أن الزونات لم تُنشأ.

### الأزرار الظاهرة

`ExecPageHeader` يعرض: **«استيراد خريطة الزون»** · إحصاءتان `الزونات = 0` و`المرجع = 21.3` ·
زرّا `إلغاء` (مخفي) و`theme`.

لا يوجد زر `ابدأ الإدراج` — لأنه لا يظهر إلا بعد `preview` صالحة.

## ③ المسار الصحيح — ما سيحدث بعد الإصلاح

### ① سكربت الزون
يُقرأ `app.map_osm_script(zoneId)` ← يولّد استعلام Overpass لحدود الزون **من مضلّعه الحقيقي**
في `gps_geofences`. الموظف ينسخه بزر «نسخ»، يلصقه في `overpass-turbo.eu` ← Run ←
Export ← raw OSM data، فيحصل على ملف `.osm`.

> **هذه هي الحلقة التي اخترتها أنت:** «سآخذ السكربت الخاص بحدودها وآخذ الملف وأدرجه بالمنصة بنفسي».

### ② إسقاط الملف
إفلات أو اختيار `.osm`/`.xml`. **يُقرأ في المتصفح بتدفّق** — لا يُرسل للخادم.
شريط تقدّم حقيقي: عقد وترد و«كم بايت قُرئ / الإجمالي». يظهر **عدد العقد والأشواط حياً**.

المحرّك مُقاس: `arkhita.osm` ٩٠ م.ب = **٠.٠٣ ثانية** · `zones.osm` ٩٣ م.ب = **٠.١٢ ثانية** ·
ملف صناعي **١٢٠ م.ب**: `assembleImport` ٤.٠٦ ثانية · ذروة الذاكرة ١٤٥٥ م.ب.

### ③ المعاينة — ٦ أرقام قبل الإدراج

| الرقم | المعنى |
|---|---|
| **شوارع** | عدد الأشواط المصنَّفة شوارع |
| **أزقة** | عدد الأزقة (تغذية بصرية منفصلة) |
| **محلات** | من أرقام OSM الرسمية (949 · 977 · 979 …) |
| **الطول الكلي** | كم |
| **المساحة** | كم² من مضلّع الزون |
| **الكثافة** | كم/كم² ← **مقارنةً بالمرجع 21.3** |

**الكثافة هي شبكة الأمان:** ضمن ±١٥٪ = أخضر «طبيعي» · حتى ±٣٥٪ = أصفر
«يستحق مراجعة الحدود أو الملف» · أكثر = أحمر.

أرقام مرجعية حقيقية من ملفاتك: أرخيته **٣٣٢** شوطاً / **٨٣.٤** كم / **٢٢.١** كم/كم² ·
الرياض ٢٩٤ / ٦١.٢ / ٢١.٢ · الواثق ٣٩١ / ٧٦.٢ / ٢٠.٩ · الجادرية ٦٥٣ / ١١٨.٤ / ٢٠.٨.

**التحذيرات الظاهرة عدا ذلك:**
- `⚠ N زقاق بلا اسم — سيُربط بـ MHL-0000 حتى يُصحَّح يدوياً`
- `⚠ N شوطاً لم يُقصّ كلياً — أُدرج كما هو`
- `✔ لا تحذيرات — الأرقام متسقة مع المرجع`

**معرض المستبعدات:** رقم الشوط · اسمه · **سبب الاستبعاد** — لا إسقاط صامت.

**الخريطة المصغّرة:** حدّ الزون خط أزرق متقاطع · **عيّنة ٥٠ شوطاً** ملوّنة بالتصنيف
(primary أحمر · secondary برتقالي · tertiary ذهبي · local أخضر مزرق · الأزقة بنفسجي).
تمرير المؤشر على شوط ← `الكود · الاسم · الطول`.

### ④ الإدراج على دفعات
`{n} دفعة × ٢٠٠ صف`. شريط تقدّم + عدّادات حيّة:
**أُدرج / حُدِّث / استُبعد**. آمن للتكرار: `on conflict (zone_id, code) do update`.
**والاسم الذي عدّله الموظف يدوياً لا يُطغى** — مُثبَت باختبار على قاعدة حقيقية.

عند النجاح: بطاقة خضراء بثلاثة أرقام (جديد · مُحدَّث · مستبعد) + `details` بأسباب أي فشل.

## ⑤ الخطة المعدَّلة — إصلاح في المصدر، لا توثيق

1. **كتب أغلفة `public` للـ١٧ دالة** التي تناديها الواجهة (نمط `00032_public_rpc_round3`).
   بينها `map_import_batch` بـ**٥ وسائط**.
2. **حارس صلاحية في كل غلاف:** `app.has_role(array['ops_room','it_admin','super_admin'])`
   ثم `raise 'MAP_FORBIDDEN'`. يُطلق **قبل** تعديل القاعدة.
3. **إدراج الزونات الثمانية** — من `gps_geofences` بأكواد ثابتة، `on conflict do nothing`.
4. **رسالة فراغ** في صفحة الاستيراد + زر «تهيئة الزونات» لمن يملك الصلاحية.
5. **تسجيل صفوف الهجرات الثلاث الناقصة** (CLI) — `insert` فقط بلا تنفيذ.
6. **حذف الصف الكاذب** `20261121234918` بعد موافقتك.
7. **تطبيق ١٦ هجرة** عبر `create_migration` باسم الملف ⇒ صفوف صحيحة بالبادئة.
8. **تحقق بعد التطبيق:** ٦٧ دالة · ١٧ غلافاً · ٨ زونات · ٤ جداول أساسية.
