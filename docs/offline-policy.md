# سياسة العمل دون اتصال (ADR 006 — الملخص التنفيذي)

## ما يعمل دون اتصال
| الجاهزية | الميزة | السلوك |
|----------|--------|--------|
| ✅ كامل | تصفح الصفحات المزارة | App Shell كاش |
| ✅ كامل | قراءة إشعار/تجاهله | client-wins + طابور |
| ✅ كامل | تسجيل حضور اليوم | client-wins + طابور |
| ✅ كامل | إنشاء طلب جديد | يُدرج محلياً "معلّق" ويُرسل عند العودة |
| ❌ محظور | أي كتابة مالية (رواتب/ميزانية) | server-wins — الزر يعطّل دون اتصال |
| ❌ محظور | رفع ملفات | يتطلب اتصالاً (Storage لا يُصفّر طابوراً) |

## القواعد الثلاث
1. كل تعارض يُحسم بمصفوفة `OFFLINE_POLICIES` — لا قرارات ارتجالية في المكونات.
2. `version` في الخادم حكم — طفرة بطبعة قديمة تُرفض دائماً.
3. المستخدم يرى دائماً: شريط Offline + عدّاد الطابور (OfflineBanner).

## مسار الترقية
localStorage → IndexedDB (`idb-keyval`) عند تجاوز 5MB أو 100 طفرة معلقة.
