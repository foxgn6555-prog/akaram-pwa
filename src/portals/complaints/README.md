# بوابة الشكاوى

- **المسار:** `/complaints`
- **الدور الحصري:** `complaints_officer`، مع إشراف `super_admin`
- **دورة الجولة الأولى:** بريد وارد ← فرز الصور ← إسناد يدوي ← معالجة مسؤول القسم ← تدقيق.

## الوحدات

1. الرئيسية
2. قاطع الكرادة
3. قاطع الزعفرانية
4. فرز وإسناد الشكاوى
5. معالجة الشكاوى
6. القوالب
7. بيانات الشكاوى
8. إعدادات الصفحات والتواصل
9. أرشيف الشكاوى
10. الدعم الفني

وحدتا القاطعين والفرز والإسناد تعملان عبر SDK. الوحدات المتبقية تعرض `UnitPlaceholder` إلى حين جولاتها.

## قواعد التطوير

- لا يُستورد Supabase داخل البوابة أو صفحاتها؛ كل قراءة وكتابة تمر عبر `src/services/`.
- بيانات الخادم تُدار عبر TanStack Query ومفاتيح مركزية فقط.
- RLS يضمن أن مسؤول القسم لا يرى إلا العناصر المسندة إلى حسابه.
- لا يسمح الخادم بإكمال الموقع دون صورة «بعد» مرتبطة ببطاقة الموقع.
- القوقعة والصفحات للعرض فقط، ومنطق الدورة في `src/features/complaints/`.
